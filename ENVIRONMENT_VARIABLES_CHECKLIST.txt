DATABRICKS_WORKSPACE_URL=https://community.cloud.databricks.com
DATABRICKS_TOKEN=your_databricks_access_token_here

# ===========================================
# HOW TO GET DATABRICKS CREDENTIALS
# ===========================================

# STEP 1: Create Databricks Community Edition Account
# 1. Go to: https://community.cloud.databricks.com/
# 2. Click "Get Started for Free"
# 3. Sign up with your email address
# 4. Verify your email
# 5. Complete the registration process

# STEP 2: Get Your Workspace URL
# 1. After logging in, look at your browser URL
# 2. It will look like: https://adb-1234567890123456.7.azuredatabricks.net/
# 3. Copy this URL (without the trailing slash)
# 4. This is your DATABRICKS_WORKSPACE_URL

# STEP 3: Create Personal Access Token
# 1. In your Databricks workspace, click on your username (top right)
# 2. Select "User Settings" from the dropdown
# 3. Click on "Access Tokens" tab
# 4. Click "Generate New Token"
# 5. Give it a name (e.g., "Retail Intelligence Project")
# 6. Set expiration (recommend 90 days for free tier)
# 7. Click "Generate"
# 8. COPY THE TOKEN IMMEDIATELY (you won't see it again!)
# 9. This is your DATABRICKS_TOKEN

# STEP 4: Create SQL Warehouse (for BI Tools)
# 1. In your workspace, click "SQL Warehouses" in the left sidebar
# 2. Click "Create SQL Warehouse"
# 3. Name it: "retail-intelligence-warehouse"
# 4. Choose "2X-Small" for free tier
# 5. Set "Auto Stop" to 10 minutes (to save credits)
# 6. Click "Create"
# 7. Note the "Connection Details" for BI tools:
#    - Server hostname: your-workspace.cloud.databricks.com
#    - HTTP path: /sql/1.0/warehouses/your-warehouse-id
#    - Port: 443

# STEP 5: Test Your Connection
# 1. Go to "Data" in the left sidebar
# 2. Click "Create Table" > "Upload File"
# 3. Upload a small CSV file to test
# 4. Create a simple query to verify everything works

# IMPORTANT NOTES:
# - Free tier has limitations (compute hours, storage)
# - SQL Warehouse auto-stops after inactivity
# - Personal access tokens expire (set calendar reminder)
# - Keep your token secure (don't share or commit to git)
